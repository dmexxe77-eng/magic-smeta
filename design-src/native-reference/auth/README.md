# Исходные страницы входа и регистрации

React Native / Expo файлы без изменений извлечены из `zamerpro-prod.zip`, предоставленного пользователем. Это справочный код; он не исполняется веб-прототипом.

Веб-версия: `src/design-bridge/login-screen.jsx`, `register-screen.jsx` и общие стили `login-screen.css`.

Сценарий макета: `/design/index.html` → вход → регистрация → вход → приложение. Принимаются любые непустые данные; аккаунты и пароли не сохраняются и не отправляются. Выход возвращает на вход, сохраняя проекты. Серверная авторизация не используется.
