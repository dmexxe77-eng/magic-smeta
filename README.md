# ЗАМЕРX

## Мобильная версия и планшеты

**Весь мобильный и планшетный прототип находится в отдельной папке [mobile-prototype](mobile-prototype/README.md).**

В ней собраны готовая вёрстка, исходники, сборка, тесты, изображения каталога и PDF с ТЗ ручного построителя для React Native. Она запускается и пересобирается самостоятельно: остальные папки репозитория для этого не нужны.

Снимок: 06.11.2026. Ветка для передачи разработчику: `codex/mobile-prototype`.

```sh
git clone --branch codex/mobile-prototype https://github.com/dmexxe77-eng/magic-smeta.git
cd magic-smeta/mobile-prototype
python3 -m http.server 5177 --directory public
```

Откройте http://127.0.0.1:5177/design/ . Порт можно заменить, если он занят. Для редактирования и тестов смотрите [инструкцию в папке мобильного прототипа](mobile-prototype/README.md).

В этой ветке автоматическая публикация Vercel отключена: она предназначена для хранения и передачи исходников. Остальные версии приложения остаются в своих исходных папках.
